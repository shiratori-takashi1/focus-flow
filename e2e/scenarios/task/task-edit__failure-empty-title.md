# 機能

[[タスク編集]] ユーザーが既存タスクの編集中にタイトルを空にして保存しようとすると、保存は行われず「タイトルを入力してください」というエラーメッセージが編集フォーム内に表示され、編集モードが継続する。

## メタ情報
- id: task-edit__failure-empty-title
- tags: task, edit, validation, negative
- related_pages: [/]

## 前提条件
- ルートページ（`/`）を開いている。
- タスク一覧は空の状態。

## 操作手順

### 1. タスクを1件追加する
- タスク入力欄（`data-testid="task-input"`）に「牛乳を買う」と入力し、"Add" ボタンをクリックする。

### 2. 編集モードに切り替える
- 「牛乳を買う」というタスク項目の編集ボタン（`aria-label="Edit \"牛乳を買う\""`）をクリックする。

### 3. タイトルを空にする
- 編集用テキスト入力欄（編集用の `data-testid="task-edit-input-{id}"`）の内容をすべて削除し、空文字にする。

### 4. 保存しようとする
- 「保存」ボタン（`aria-label="Save edit"`）をクリックする。

## 検証内容
- 編集用フォーム内にエラーメッセージ「タイトルを入力してください」（role="alert"）が表示される。
- タスクは編集モードのままであり、通常表示（保存済みタイトル表示）には戻らない。
- 一覧上のタスクタイトルは変更されていない（キャンセルボタンをクリックした場合、元のタイトル「牛乳を買う」が表示されることでも確認できる）。
