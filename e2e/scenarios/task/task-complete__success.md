# 機能

[[タスク完了切り替え]] ユーザーがタスクのチェックボックスをクリックすると、そのタスクが完了状態になり、タイトルに取り消し線が付き、進捗バー・進捗パーセンテージが更新される。再度クリックすると未完了状態に戻る。

## メタ情報
- id: task-complete__success
- tags: task, complete, toggle, progress, happy-path
- related_pages: [/]

## 前提条件
- ルートページ（`/`）を開いている。
- タスク一覧は空の状態。

## 操作手順

### 1. タスクを1件追加する
- タスク入力欄（`data-testid="task-input"`）に「牛乳を買う」と入力し、"Add" ボタン（`data-testid="add-task-btn"`）をクリックする。
- 追加直後、進捗表示（`data-testid="progress-text"`）が "0%" であることを確認する。

### 2. タスクのチェックボックスをクリックして完了にする
- 「牛乳を買う」というタスク項目内のチェックボックス（`aria-label="Mark \"牛乳を買う\" as complete"`）をクリックする。

### 3. 完了状態を確認する
- チェックボックスがチェック済み状態になり、`aria-label` が `Mark "牛乳を買う" as incomplete` に変わることを確認する。
- タスクタイトルの表示に取り消し線（打ち消し線スタイル）が付くことを確認する。
- 進捗表示（`data-testid="progress-text"`）が "100%" に、進捗バーの `progressbar` の `aria-valuenow` が `100` に更新されることを確認する。

### 4. 再度チェックボックスをクリックして未完了に戻す
- 同じチェックボックスを再度クリックする。

## 検証内容
- チェックボックスが未チェック状態に戻り、`aria-label` が `Mark "牛乳を買う" as complete` に戻る。
- タイトルの取り消し線表示が解除される。
- 進捗表示が "0%" に戻る。
