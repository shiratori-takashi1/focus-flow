# 機能

[[タスク編集]] ユーザーが既存タスクの編集ボタンをクリックしてタイトルを変更し保存すると、一覧上のタスクタイトルが新しい内容に更新される。

## メタ情報
- id: task-edit__success
- tags: task, edit, happy-path
- related_pages: [/]

## 前提条件
- ルートページ（`/`）を開いている。
- タスク一覧は空の状態。

## 操作手順

### 1. タスクを1件追加する
- タスク入力欄（`data-testid="task-input"`）に「牛乳を買う」と入力し、"Add" ボタンをクリックする。

### 2. 編集モードに切り替える
- 「牛乳を買う」というタスク項目の編集ボタン（`aria-label="Edit \"牛乳を買う\""`）をクリックする。
- タスクタイトルの表示がテキスト入力欄（編集用の `data-testid="task-edit-input-{id}"`、`{id}` はタスクごとのID）に切り替わり、値が「牛乳を買う」で初期表示されていることを確認する。
- 「保存」ボタン（`aria-label="Save edit"`）と「キャンセル」ボタン（`aria-label="Cancel edit"`）が表示されていることを確認する。

### 3. タイトルを書き換える
- 編集用テキスト入力欄の内容をすべて削除し、「パンを買う」と入力する。

### 4. 保存する
- 「保存」ボタン（`aria-label="Save edit"`）をクリックする。

## 検証内容
- 編集モードが終了し、通常表示に戻る。
- タスクタイトルの表示が「パンを買う」に更新される。
- エラーメッセージは表示されない。
- タスクの完了状態は変更前と変わらない（未完了のまま）。
