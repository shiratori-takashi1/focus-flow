# 機能

[[タスク追加]] ユーザーがタイトルを入力せずに（または空白文字のみで）タスク追加を試みると、タスクは追加されず、「タイトルを入力してください」というエラーメッセージが表示される。

## メタ情報
- id: task-add__failure-empty-title
- tags: task, add, validation, negative
- related_pages: [/]

## 前提条件
- ルートページ（`/`）を開いている。
- タスク一覧は空の状態。

## 操作手順

### 1. タスク一覧ページを開く
- ブラウザで `http://localhost:3000/` にアクセスする。

### 2. 何も入力せずにタスクを追加しようとする
- タスク入力欄（`data-testid="task-input"`）に何も入力しない。
- "Add" ボタン（`data-testid="add-task-btn"`）をクリックする。

### 3. エラー内容を確認する
- エラーメッセージ（`data-testid="add-task-error"`、role="alert"）に「タイトルを入力してください」と表示されることを確認する。
- 件数表示 "0 Tasks Today" が変わらないことを確認する。

### 4. 空白文字のみでタスクを追加しようとする
- タスク入力欄に半角スペースのみ（例: "   "）を入力する。
- "Add" ボタンをクリックする。

## 検証内容
- 手順3・4のいずれの場合も、タスク一覧に新しいタスクは追加されない（件数表示は "0 Tasks Today" のまま）。
- エラーメッセージ（`data-testid="add-task-error"`）に「タイトルを入力してください」と表示される。
- 空状態メッセージ "Nothing to focus on?" が表示され続ける。
